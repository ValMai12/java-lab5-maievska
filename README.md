
# I/O Streams

Лабораторна робота з Java на тему роботи з потоками введення та виведення.

## Завдання

1. Пошук рядка з максимальною кількістю слів у текстовому файлі.
2. Збереження та завантаження об'єктів з використанням серіалізації.
3. Шифрування та дешифрування символьних потоків.
4. Підрахунок HTML-тегів вебсторінки та сортування результатів.

## Технології

- Java 21
- Maven
- JUnit 5
- jsoup

## Запуск

Спочатку потрібно скомпілювати проєкт:

`mvn clean test`

### Завдання 1

`mvn exec:java -Dexec.mainClass=TextFileApp`

Програма запитує шлях до текстового файлу та знаходить рядок з найбільшою кількістю слів.

Приклад файлу: `sample-data/text.txt`

### Завдання 2

`mvn exec:java -Dexec.mainClass=Main`

Консольний каталог книг з можливістю пошуку, сортування, збереження та завантаження об'єктів.

Для роботи з файлами використовуються ObjectOutputStream та ObjectInputStream.

### Завдання 3

`mvn exec:java -Dexec.mainClass=TextCipherApp`

Програма шифрує та дешифрує текстові файли за допомогою ключового символу.

Використовуються FilterWriter та FilterReader.

### Завдання 4

`mvn exec:java -Dexec.mainClass=HtmlTagApp`

Програма завантажує HTML-сторінку за введеним URL, підраховує частоту появи тегів і виводить результати в лексикографічному порядку та за зростанням частоти.

## Тестування

Для запуску автоматичних тестів:

`mvn clean test`

Проєкт містить 34 автоматичні тести.

## Структура

- `src/main/java` — основний код програм.
- `src/test/java` — автоматичні тести.
- `sample-data` — приклад текстового файлу.
- `data` — файли, створені під час роботи програм (не додаються до Git).
